### [AWS Data Lakehouse Pipeline](https://github.com/vfreis/aws_data_lakehouse_pipeline)

A production-inspired AWS data platform that ingests, validates, transforms, and curates data using scalable distributed processing.

```text
External APIs
    ↓
S3 Bronze — immutable raw data
    ↓
Data-quality checks
    ↓
PySpark processing on AWS EMR
    ↓
S3 Silver — validated and curated data
    ↓
Analytics · BI · AI workloads
```

**Engineering highlights**

- Modular ingestion, transformation, and validation components.
- Batch and incremental processing patterns.
- Apache Airflow orchestration with retries and dependency control.
- PySpark transformations and optimized Parquet output.
- Data-quality checks, logging, and production-oriented separation of concerns.
- Datasets structured for downstream analytics and AI use cases.

[**Explore the architecture and source code →**](https://github.com/vfreis/aws_data_lakehouse_pipeline)
